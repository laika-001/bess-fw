# Anomaly autoencoder (runs on the MAX32630)

A small autoencoder learns what healthy operation looks like and scores every
frame on the module itself (`../anomaly.h`). The score goes out in the frame
(`anom_pct`, % of the learned limit) and the module sets the frame flag
`F_LOCAL_ALARM` (0x0020) when it stays above the limit. The Pi dashboard only
displays both.

## What it looks at

Behaviour, not levels (absolute limits are the dashboard's threshold alerts):
temperature rate and its step from the 30-min median, enclosure pressure mean
and fluctuation over 1 min, gas resistance change and rate (320 °C step only),
humidity rate and step. Definitions: `bess_features.py`.

Network 8 -> 6 -> 3 -> 6 -> 8 (tanh). Score = mean squared reconstruction error;
limit = 1.2 x the 99.9th percentile on the healthy data. Alarm after 5 frames
above (15 s), clears after 10 below; the dashboard shows critical above 3x.
No score for 30 min after each module boot (the windows fill).

## Current model

Trained 2026-10-15 on 02:00-07:30 (5.5 h, quiet night, 6599 vectors):
0 alerts on the healthy data. Replaying 07:30-10:15 it raised 6 alerts, all
real events in the logs: gas drops when people arrived (08:19, 09:33, up to
35x the limit) and the 750 Pa pressure spike at 09:53 (70x).

**One night is a narrow idea of "healthy".** Daytime activity (people, HVAC,
cleaning) will raise alerts until the model has seen it. Retrain on several
days that include normal daytime, with nothing unusual going on.

## Retrain and deploy

```bash
# 1. train on a healthy period (logs/ from tools/bess_rx.py, or the Pi's /var/lib/bess-dashboard CSVs)
/opt/homebrew/bin/python3 ml/train_autoencoder.py --csv 'logs/*.csv' \
    --train 2026-10-16T00:00 2026-10-18T00:00 --test 2026-10-18T00:00 2026-10-18T12:00
# 2. check the firmware code matches the Python reference on real frames
/opt/homebrew/bin/python3 ml/check_firmware_anomaly.py --csv 'logs/*.csv'
# 3. build and flash (anomaly_model.h is regenerated by step 1)
bessflash
```

Training needs numpy (Homebrew's python3 has it). Files: `model.json` (the model),
`anomaly_model.h` (generated weights for the firmware), `export_model.py`.
